# Hermes on Hetzner — Setup Checklist (Tailscale-Only, No Domain)
> When you're ready, follow this step-by-step. All scripts are pre-written. Total time: ~30 min.

---

## ✅ What I've Already Built For You

- `hetzner/bootstrap.sh` — pasted on the server after first SSH (installs everything)
- `hetzner/deploy.ps1` — run from your PC to push Hermes files to the server
- `hetzner/hermes-server.js` — HTTP wrapper for status + trigger endpoints
- `hetzner/hermes-jobs.json` — starter job catalog (5 jobs, expandable)
- `hetzner/HERMES-RUNBOOK.md` — ops manual (restart, view logs, recover)

You only need to do the **5 manual steps** below.

---

## Step 1 — Generate an SSH Key (5 min, one time)

On your PC, open PowerShell:

```powershell
ssh-keygen -t ed25519 -C "woody-aios"
```

Press Enter through all the prompts (accept default path, no passphrase if you want it simple — or set one for extra security).

Then copy your public key to clipboard:

```powershell
Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | Set-Clipboard
```

That's now in your clipboard. You'll paste it in Step 3.

---

## Step 2 — Create Hetzner Account (5 min, one time)

1. Go to **https://www.hetzner.com/cloud**
2. Click **"Sign Up"** → use your Gmail
3. **Use a strong unique password** — save it in 1Password / Bitwarden, do NOT reuse from anywhere
4. Verify email
5. Add a card (no charge yet, just verification)
6. **CRITICAL — enable 2FA immediately:** Settings → Security → Two-factor authentication. Use Authy / Google Authenticator. Save the recovery codes somewhere safe.
7. **Set a spending limit:** Settings → Billing → set a $15/month cap so you can't be surprise-billed
8. You'll see the Hetzner Cloud Console — click **"+ New Project"** → name it **`AIOS`**

> Why this matters: Hetzner is the single point of control. A compromised Hetzner password = full access to the server. Strong password + 2FA closes this completely. Read [SECURITY.md](SECURITY.md) for the full audit.

## Step 3 — Spin Up the Server (3 min)

In the AIOS project:

1. Click **"Add Server"**
2. **Location:** Ashburn, VA (closest to Houston)
3. **Image:** Ubuntu 24.04
4. **Type:** Click "Shared vCPU" tab → select **CX22** ($4.15/mo, 2 vCPU, 4GB RAM)
5. **Networking:** Leave defaults (public IPv4 + IPv6)
6. **SSH Keys:** Click **"+ Add SSH Key"** → paste from your clipboard → name it `woody-pc`
7. **Volumes / Firewalls / Backups:**
   - **Enable Backups** ($0.83/mo — daily snapshots)
8. **Name:** `hermes`
9. Click **"Create & Buy Now"**

In ~30 seconds you'll see a green dot and an IP address. Copy that IP — you'll need it for Step 4.

---

## Step 4 — SSH In and Run Bootstrap (10 min)

In PowerShell on your PC:

```powershell
ssh root@<YOUR-HETZNER-IP>
```

Type `yes` when it asks about the fingerprint. You're now on the server.

**Paste this single command** (downloads and runs the bootstrap script from your repo):

```bash
curl -fsSL https://raw.githubusercontent.com/<your-github-user>/everything-claude-code/main/dashboard/hetzner/bootstrap.sh | bash
```

**OR** if your repo is private, just paste the contents of `hetzner/bootstrap.sh` directly. The script will:
- Update system + install firewall + fail2ban
- Install Node 20, PM2
- Install Tailscale
- Create a `hermes` user (not running as root)
- Create directory structure at `/home/hermes/`
- Output the Tailscale auth URL

When it prints **"Tailscale auth URL:"**, click that link in your browser, log in with Google (or create an account), authorize the device. The server will then have a Tailscale IP like `100.x.x.x`.

When it finishes, you'll see:

```
✅ BOOTSTRAP COMPLETE
   Tailscale IP: 100.x.x.x
   Hermes user: /home/hermes/
   Next step: run deploy.ps1 from your PC
```

Save that Tailscale IP — you need it in Step 5.

---

## Step 5 — Deploy Hermes (5 min)

Back on your PC (PowerShell), in the dashboard folder:

```powershell
cd "C:\Github Repos\everything-claude-code\dashboard"
.\hetzner\deploy.ps1 -ServerIp <hetzner-public-ip>
```

This:
1. Copies `hermes.js`, `hermes-jobs.json`, all job scripts to the server
2. Installs npm dependencies remotely
3. Creates `.env` from your local API keys
4. Starts Hermes via PM2
5. Verifies it's running

When done, it prints:

```
✅ HERMES DEPLOYED
   Status: running (PID xxxx)
   API: http://woody-hermes.tail-xxxx.ts.net:3001/status
   Add to dashboard/.env.local:
     HERMES_ENDPOINT=http://woody-hermes.tail-xxxx.ts.net:3001
     HERMES_TOKEN=<auto-generated>
```

Paste those two lines into your `dashboard/.env.local` and restart `npm run dev`. The dashboard `/hermes` page will now show live status from your remote Hermes.

## What Tailscale Needs (3 min, one time)

You'll need Tailscale on your PC too so it can reach the Hetzner server:

```powershell
winget install Tailscale.Tailscale
```

After install, click the system tray icon → log in (same account you used in Step 4). That's it.

You can also install Tailscale on your iPhone to access Hermes from your phone (`https://tailscale.com/download/ios`).

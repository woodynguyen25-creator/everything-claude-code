## Scoring (research-backed mix)

Replaced Lewis Jackson's original 50/30/20 with institutional-style weighting:

```
Sharpe   35%    risk-adjusted return — the headline metric
Calmar   30%    return / max drawdown — Druckenmiller's favorite
Sortino  20%    downside-only volatility
Hit rate 10%    consistency
Raw ret   5%    tiebreaker, not the goal
```

Hard caps: realized return below failure floor pins score to -0.5. Drawdown breach pins it to -0.3 even if the return looks fine.

## Reflection cascade

Every 6h per asset:

1. **DeepSeek-V3** (preferred, when `DEEPSEEK_API_KEY` is set) — best price/quality for structured JSON reasoning over ~3-5k context. ~$0.0001 per cycle.
2. **Hermes CLI** (free fallback) — calls `hermes -z` which routes to Gemini Flash by default. Costs nothing.
3. **Deterministic rules** (final fallback) — if both LLMs unavailable, applies one-variable change based on score components (loosen entry if underperforming, tighten stop if drawdown breached).

Each reflection changes exactly ONE strategy variable and bumps version (01 → 02 → 03...). Telegram alert on every cycle.

## SECTION 5 — STYLE LOCK DOCUMENTATION

### What worked

- Two-render `--sref` pair (Thor + Thor alt) → most consistent style across all subsequent renders
- `--style raw` consistently → kept Midjourney from over-prettifying
- Real actor references ("face like Robb Stark or Uhtred of Bebbanburg") → grounded physicality
- Environmental storytelling ("ash motes in air," "fissures in basalt") → killed the "AI fantasy poster" look
- Asymmetric poses ("half-turned," "mid-throw," "perched") → never head-on stiff

### What didn't work

- **Multiple style refs from different artists** — diluted the lock, looked like blended AI art
- **"Cinematic" without specific lighting** — too generic; always specify lighting source + direction
- **Symmetrical centered figure** — every render came out feeling like a tarot card. Off-center > centered
- **Generic fantasy adjectives** ("majestic," "fierce," "heroic") — Midjourney converges on stock fantasy. Use specific moods instead ("restrained power," "measured cocky")
- **Mixing mythologies in one render** — first Lebot attempt had both NBA jersey AND Norse cloak which fought. Locked: one mythology element dominates per render

### Aspect ratios used

- `4:5` — agent banners (heroes), feels portrait-cinematic
- `1:1` — agent sigils (sidebar small avatars)
- `16:9` — scenes (wide establishing shots, hero band backgrounds)

Do NOT use:
- `3:4` (too snapshot-y)
- `9:16` (too phone-vertical, doesn't fit dashboard)
- `2:1` (too letterbox, awkward in hero band)

## SECTION 6 — PRODUCTION CHECKLIST

When generating a new render:

1. [ ] Use the 5-part prompt grammar (subject, action, environment, lighting, style lock)
2. [ ] Include `--sref {locked-pair} --sw 200` (the Thor style ref pair, weight 200)
3. [ ] Include `--style raw --v 6.1` (or current latest version)
4. [ ] Pick aspect ratio from the allowed list
5. [ ] Reference a real actor for physicality if portrait
6. [ ] Add environmental storytelling detail
7. [ ] Specify lighting direction + temperature
8. [ ] Generate 4 variations, pick best
9. [ ] If best is acceptable: upscale + download PNG
10. [ ] Convert PNG → WebP at quality 85: `ffmpeg -i input.png -quality 85 output.webp`
11. [ ] Save WebP to `public/art/agents/heroes/{slug}.webp` or `public/art/scenes/{slug}.webp`
12. [ ] Backup original PNG to `public/art/.originals/{slug}.png`
13. [ ] Update this prompt bank with the confirmed prompt + status tag
14. [ ] Update `public/art/RENDERS-MANIFEST.md` with the new asset
